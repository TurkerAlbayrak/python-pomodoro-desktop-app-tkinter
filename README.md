# Tkinter ile Pomodoro Masaüstü Uygulaması

Bu proje, Python ve Tkinter kütüphanesi kullanılarak geliştirilmiş, zaman yönetimi ve odaklanmayı artırmayı hedefleyen bir Pomodoro masaüstü uygulamasıdır.

## Özellikler

* 25 dakikalık çalışma ve 5 dakikalık mola sürelerini otomatik olarak yönetir.
* Geri sayım sayacı ile kalan süreyi görsel olarak gösterir.
* Kullanıcı dostu ve sade bir masaüstü arayüzüne (GUI) sahiptir.

## Gereksinimler

* Python 3.x
* Tkinter (Python ile birlikte yerleşik olarak gelmektedir)

## Kurulum ve Çalıştırma

1. Projeyi bilgisayarınıza indirin veya klonlayın:
   ```bash
   git clone [https://github.com/TurkerAlbayrak/python-pomodoro-desktop-app-tkinter.git](https://github.com/TurkerAlbayrak/python-pomodoro-desktop-app-tkinter.git)
Proje dizinine gidin:

Bash
cd python-pomodoro-desktop-app-tkinter
Uygulamayı çalıştırın:

Bash
python pomodoro.py
